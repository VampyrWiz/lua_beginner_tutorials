# lua_beginner_tutorials

A Lua beginner tutorial. Requires [Lua](https://www.lua.org/) (5.x).

Run any file from the repo root:

```sh
lua "First Lua Script/hello_world.lua"
lua TicTacToe/tictactoe.lua
```

## Lessons

- **First Lua Script**: hello world, variables, escape characters
- **Variables and Data Types**: data types, operators, tables
- **Control Statements**: if, loops, conditionals
- **Functions**: defining and calling functions
- **File I/O**: reading and writing files

## Projects

- **TicTacToe**: tic-tac-toe vs AI with Easy/Medium/Hard/Impossible difficulty (Minimax)
